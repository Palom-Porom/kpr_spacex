# SpaceX Stats — лабораторная работа

Готовое решение лабораторной на базе оригинального проекта **kpr_spacex**. Слева выводятся запуски SpaceX, справа — карта мира и стартовые площадки. Наведение мыши или фокус с клавиатуры на запуск подсвечивает площадку, с которой выполнялся запуск. Точки можно также выделять наведением непосредственно на карте.

**Источник данных:** [Launch Library 2 API v2.3.0](https://ll.thespacedevs.com/docs) от The Space Devs. Старый `api.spacexdata.com/v4` в решении **не используется**.

## Быстрый запуск

Понадобятся **Node.js 20+** и **npm** (npm устанавливается вместе с Node.js).

1. Распакуйте архив в любую папку.
2. Откройте терминал в папке, где лежит `package.json`.
3. Выполните:

```bash
npm ci
npm start
```

4. Откройте URL, указанный Parcel в терминале; обычно это **http://localhost:1234**.

`npm ci` устанавливает зависимости по `package-lock.json`, в том числе D3.js и Parcel. Для отображения реальных данных нужен доступ к интернету.

### Если API недоступен или сработал лимит запросов

Для проверки всей интерактивности **без запросов к API** откройте:

**http://localhost:1234/?demo=1**

Это отдельный демонстрационный режим с **учебными записями**, НЕ реальные ответы API. В заголовке появится бейдж «ДЕМО · учебные данные». Данные в обычном режиме не подменяются демонстрационными молча.

Чтобы вернуться к реальным запускам, откройте http://localhost:1234/ без `?demo=1`.

### Запуск в Windows

Команды `npm ci` и `npm start` можно выполнять в PowerShell или терминале VS Code. Если PowerShell блокирует скрипты `npm.ps1`, используйте команды `npm.cmd ci` и `npm.cmd start` (либо откройте CMD).

## Что выполнено по README задания

1. **API-методы:** `src/api/spacex.js` содержит `launches()`, `launchpads()` и `launchpad(id)`; они обращаются к `/launches/previous/`, `/pads/`, `/pads/{id}/` Launch Library 2. Добавлены обработка не-2xx ответов, API-ограничения 429, кеширование на 30 минут в `localStorage` и поддержка постраничной выдачи площадок.
2. **Площадки на карте:** `src/data.js` преобразует данные в `FeatureCollection` с геометрией `Point` и координатами `[longitude, latitude]`. `src/index.js` отображает GeoJSON с помощью D3.js и проекции Natural Earth.
3. **Интерактивность:** у каждого запуска API содержит объект `pad`, его `pad.id` сопоставляется с `Feature.properties.id`. При `mouseenter`, `focus` или нажатии подсвечивается нужный круг; при уходе курсора подсветка сбрасывается. Площадка отображается в панели под картой.

Дополнительно добавлены поиск по названию, адаптивная верстка, обработка отсутствующих координат и недоступного API, режим учебных данных и тесты.

## Важные особенности API

- `lsp__id=121` отбирает запуски SpaceX.
- `agencies_ids=121` отбирает площадки, связанные с SpaceX.
- Параметр `mode=normal` нужен для получения вложенного поля `pad` у запусков: `mode=list` может не содержать эту связь.
- API возвращает массив не напрямую, а в поле `results`, а также `next` при наличии следующей страницы.
- В списке показываются **80 последних завершённых запусков**, а не все запуски за всю историю SpaceX. Число меняется в `client.launches()` в `src/index.js`.
- Для площадок без координат точка не рисуется. Если фильтр площадок не вернул площадку, но она присутствует во вложенном объекте запуска, код дополнит список данными запуска.
- По [документации](https://ll.thespacedevs.com/docs) анонимные запросы к production API ограничены (на момент разработки — 15 запросов в час). Чтобы не тратить лимит при каждом обновлении страницы, данные кешируются на 30 минут. Кнопка **«Обновить»** удаляет кеш приложения и делает новые запросы.
- Платформа предоставляет тестовый хост `https://lldev.thespacedevs.com/2.3.0/` с устаревшими/ограниченными данными и без лимита запросов. Чтобы использовать его вместо production, замените `DEFAULT_BASE_URL` в `src/api/spacex.js`. Демо-режим не обращается ни к одному хосту API.

## Тестирование

```bash
npm test
```

Тесты выполняются штатным Node.js test runner, не требуют интернета и проверяют построение GeoJSON, связи по идентификаторам, формирование API-запросов, пагинацию, обработку 429 и кеш.

## Сборка для публикации

```bash
npm run build
```

Parcel создаст новую папку `docs/` с собранным приложением (старые собранные файлы исходного проекта из конечного архива удалены, поскольку содержали устаревшую версию).

Не открывайте `index.html` напрямую через `file://` — импорты и зависимости требуют сборщика/локального сервера.

## Структура

```text
index.html             Разметка приложения

package.json           npm-команды и зависимости
package-lock.json      Зафиксированные зависимости
```
